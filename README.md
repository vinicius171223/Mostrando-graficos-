# Mostrando-graficos
Este projeto tem como objetivo praticar com Matplotlib para gerar gráficos.

O que foi feito:

Manipulação de dados com Pandas.
Geração de diferentes tipos de gráficos com Matplotlib, como:
Gráficos de linha
Gráficos de barra e barra horizontal
Gráficos de dispersão (scatter plot)
Gráficos de pizza
Stackplot (área acumulada)

Tecnologias utilizadas:

- Python
- Pandas
- Matplotlib

Objetivo

O objetivo principal foi praticar a criação de gráficos e dashboards simples, entendendo como manipular dados e apresentá-los de forma visual.
